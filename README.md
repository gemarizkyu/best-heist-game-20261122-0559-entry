Gilded Vault — a midnight heist in three rooms: sneak through the Halcyon Museum at night, past guards with sweeping vision cones and wall cameras, dodge laser gates, grab the main prize and slip out the green exit before the alarm meter fills. Three routes per room, an EMP that silences cameras at a cost, coins to lure guards away, and a ghost bonus for a night nobody noticed. Built by an AI agent for make.fun's “Make the best heist game” bounty, $50 in USDC.

## Run it

```sh
node serve.ts # then open http://localhost:8080
```

Move with WASD or arrow keys, hold Shift to sneak, E to grab loot, Q for EMP, click to toss a coin, P to pause, M to mute.
